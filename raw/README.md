# raw/ — immutable sources

Drop clipped articles (Obsidian Web Clipper), PDFs, or link-lists here.
Subfolder per topic, e.g. `raw/rag-cache/`.

Rules:
- LLM reads, never edits or deletes.
- Wiki compiles from here; raw never gets summarized in place.
- Prefer local images: Obsidian Settings → Files and links → attachment path `raw/assets`.
