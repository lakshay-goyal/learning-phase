# Decisions — why, not what

| Date | Decision | Reason | Rejected alternative |
|---|---|---|---|
| 2026-10-02 | 3 files per topic, evidence in `.agents/evidence/` | Keeps Obsidian graph neat; machine proof stays out of the reading path | 7-file research package (hop hell) |
| 2026-10-02 | Offline-default gate, `--probe` opt-in for URL checks | Vault must verify without network; live checks are warnings-first | Always-online gate (flaky) |
| 2026-10-02 | Tracks: hub `<Track>.md` + N subtopic triples, budgets README≤350/build≤250/resources≤150/hub≤150 | User syllabus needs full coverage + hub navigation; 3-file cap could not hold 35 items | Single mega-note (unsearchable) / 12 flat topics (no navigator) |
| 2026-10-02 | Descriptive filenames HARD RULE: `<Slug>.md` + `<Slug>.resources.md` + `<Slug>.build.md`, banned generic list in config, gate fails violations | Obsidian graph/search shows filenames — 8× README.md nodes unreadable; user explicitly banned readme/build/sources-only names | Keep README triple + rely on frontmatter titles (invisible in graph) |
| 2026-10-02 | Beginner-first, snippet-first output (rule 12): plain words, zero jargon, snippet per concept, real use + edge cases, no storytelling, no context dumps | Fresher with zero background + low attention span learns from runnable snippets, not paragraphs; each section must end with something they can DO | Long explainer prose with jargon (readable only after 5 paragraphs) |
| 2026-10-02 | v5: ONE resources + ONE build per topic/track, note-only subtopics (no per-subtopic triples); resources = beyond-scope only, build = whole-topic mini-projects | Per-subtopic triples repeated the same sections 8× and turned assignments into homework; one common file per topic is easier to find, review, and keep valuable | Keep per-subtopic triples (8 resources + 8 build files per track) |
| 2026-10-02 | v6: tracks fold into notes/ (all `<Slug>.md` together) + context/ (`<Track>.resources.md` + `<Track>.build.md`); no per-subtopic folders | One folder per single-file note was pointless overhead in the explorer; two named folders are scannable and self-describing | Keep one folder per subtopic note |
| 2026-10-02 | Folder-named domain hubs replace _MOC.md; star topology (domain→hubs, notes→hub) | Obsidian graph showed _MOC nodes + dead index/DevOps/stale-subtopic nodes + mesh; folder-named hubs read as domain names and hubs size up | Keep _MOC + full mesh (unreadable graph) |
| 2026-10-02 | Bullet format law: breathing room + explain-every-bullet + visual-first | Reader feedback: dense keyword bullets with no spacing are unreadable; each bullet must teach alone in 1–2 lines with blank lines around it | Keyword-chip bullets stacked on fences (compact but incomprehensible) |
